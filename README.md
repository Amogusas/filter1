# Кофейня «Фильтр» — сайт-страница

Одностраничный сайт с интерактивной картой и меткой для кофейни «Фильтр»
(ул. Бурхана Шахиди, 7, Казань).

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Всё в одном файле: разметка, стили и скрипты. |
| `images/` | Оригинальные фото заведения (скачаны с Яндекс Карт). |

## Как открыть

Просто откройте `index.html` двойным кликом в браузере.

Интерактивная карта — это встроенный виджет Яндекс Карт (`iframe` с
`yandex.ru/map-widget`). Он не требует API-ключа и работает там, где
доступен yandex.ru. Всё остальное — обычный HTML/CSS/JS без внешних
зависимостей.

## Что на странице

- Шапка с навигацией и кнопкой «Позвонить».
- Hero-блок с названием, описанием и рейтингом (4.7, 164 оценки).
- Блок **«Как нас найти»** — встроенная карта Яндекса с меткой заведения
  (по координатам `55.788321, 49.103816`) и панель с адресом, телефоном,
  метро и часами.
- Кнопка «Построить маршрут» (открывает Яндекс Карты).
- Блок **«Меню»** — кофе, авторские напитки, десерты и еда.
- Блок **«Фото»** — галерея оригинальных фотографий заведения.
- Блок особенностей и цен.
- Контакты и подвал.

## Про меню

Официального меню с ценами в открытом доступе нет (на 2ГИС карточка
помечена «Добавить фото меню»). Поэтому меню собрано из публичных данных:
особенностей на Яндекс Картах, тегов 2ГИС и упоминаний в отзывах. Известная
цена — капучино 300–340 ₽ (Яндекс Карты), средний чек — около 500 ₽.
Остальные цены не выдуманы и не указаны — их можно добавить вручную.

## Про фото

Все изображения — оригиналы (`/orig`) из галереи заведения на Яндекс Картах,
скачаны в папку `images/`. Источник: Яндекс Карты.

## Данные места

- **Название:** кофейня «Фильтр»
- **Адрес:** ул. Бурхана Шахиди, 7, Казань (1 этаж)
- **Телефон:** +7 (952) 404-20-70
- **Метро:** «Кремлёвская», ~960 м
- **Координаты:** 55.788321, 49.103816
- **Источник:** карточка на Яндекс Картах

> Это неофициальная страница заведения. Данные (рейтинг, цены, особенности,
> часы работы) взяты из публичной карточки на Яндекс Картах и могут меняться.

## Как поменять данные

- **Координаты и метка:** в `index.html` найдите `iframe` в блоке `<!-- Map -->`
  и поправьте параметры в `src`: `ll` (долгота,широта), `z` (масштаб),
  `oid` (id организации), `pt` (метка).
- **Текст, адрес, телефон:** правьте прямо в разметке — комментарии
  `<!-- Map -->`, `<!-- Features -->` и т.д. подскажут, где что.
